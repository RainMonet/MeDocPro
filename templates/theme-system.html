Implementation Guide
How to integrate theme system into your MeDocPro components

CSS Custom Properties Approach

Replace hardcoded colors and font sizes in your existing components with CSS custom properties for seamless theme and accessibility switching.

/* Before: Hardcoded styles */ .patient-item { background: #ffffff; border: 1px solid #e2e8f0; color: #1a365d; font-size: 14px; padding: 12px; } /* After: Theme and accessibility aware */ .patient-item { background: var(--theme-surface); border: 1px solid var(--theme-border-light); color: var(--theme-text-primary); font-size: calc(var(--font-size-sm) * var(--text-scale)); padding: var(--space-text-md); }

JavaScript Theme & Text Size Controller

// Enhanced theme management with text scaling class ThemeManager { constructor() { this.currentTheme = localStorage.getItem('medocpro-theme') || 'clinical'; this.currentTextSize = localStorage.getItem('medocpro-text-size') || 'medium'; this.applyTheme(this.currentTheme); this.applyTextSize(this.currentTextSize); } setTextSize(size) { this.currentTextSize = size; this.applyTextSize(size); localStorage.setItem('medocpro-text-size', size); this.notifyComponents(); } applyTextSize(size) { document.body.setAttribute('data-text-size', size); } }
Accessibility & Clinical Usability
All themes maintain WCAG 2.1 AA compliance with minimum 4.5:1 contrast ratios. Text scaling from 87.5% to 150% accommodates various visual needs common in medical settings. Large text options support providers using tablets during patient encounters and those with visual impairments.

Integration Steps

  1. Add CSS custom properties for colors and typography to your stylesheets
  2. Replace hardcoded colors and font sizes with theme variables
  3. Implement theme and text size selector components
  4. Add localStorage persistence for user preferences
  5. Test with all components ensuring accessibility compliance
  6. Validate text scaling works properly in clinical workflows
